PIXEL ARENA OWNER PORTAL - DEMO

Open index.html in a modern browser.
Demo PIN: 2468

Features:
- Mark slots available, booked offline, booked, or maintenance
- Generate today's hourly slots for all four sports
- Configure weekend Saturday/Sunday offers
- Edit day/night rates
- Export a JSON backup

IMPORTANT LIMITATION:
This is a standalone front-end prototype. Data is saved only in the current browser using localStorage. It does not sync with the customer-facing website or other devices, and the demo PIN is not secure authentication. Before production use, connect a backend/database, implement real owner login and permissions, and connect offers/availability to the public site.
